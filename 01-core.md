# CORE — live facts (template)

> The only file every agent/model MUST read at the start of every session.
> Hard limit: ~60 lines. If it grows — move facts out to handbooks.
> When a fact changes: strike the old line and write the new one next to it, with a date.

## Who we are (never changes)
- One shared brain, two equal models (cloud + local). Owner is the arbiter.

## Protocol
1. Read CORE + your own memory before any task.
2. Diary is append-only. Never delete; strike and supersede.
3. After every big task: one line in the diary (date + result + lesson).
4. Secrets never go into notes, diaries, or any memory file.
5. Weekly: consolidate the diary. Monthly: distill + EXAM (see exam/exam-form.md).
