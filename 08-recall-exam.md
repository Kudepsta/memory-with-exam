# RECALL EXAM — a second exam: memory recall, not compression (template)

> The compression exam (exam-form.md) proves a digest kept what mattered. The recall exam
> proves the *system* can still answer questions about its own history — and finds the
> sections where it cannot. Added November 2026; the first run is documented below,
> failure included.

## The ritual (monthly)

1. **Question writer.** Model A writes 20 questions about the company's history for the past
   period: decisions, numbers, incidents, lessons. Only from memory files — no browsing.
2. **Cold exam.** Model B answers in a fresh session, WITHOUT reading the files first.
   An honest "I don't remember" is the required answer when that is the truth —
   guessing is forbidden and scores zero.
3. **Bar: 17/20.** Self-graded first, then checked against the files.
4. **Distill the failures.** Every failed topic names a weak memory section: the fact lived
   only in a collapsed diary, or was never promoted to CORE. Fix the section, not the student.

## First run, honestly: FAILED (self-graded 8–11 of 20)

Our first recall exam (November 2026) did not pass its own bar. The weak area was exactly
what the exam exists to find: a two-month-old period whose details lived only in the
consolidated diary. Two conclusions, both kept:

- The system's memory is retrieval-based ("read + search"), not verbatim. Like a librarian
  who knows which shelf holds what — not one who recites the books. The exam measures
  whether the shelves are labeled well enough for that.
- An exam that cannot fail is not an exam. We publish the failure because it is the
  cheapest evidence that the gate is real.
