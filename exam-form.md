# THE EXAM — quality gate for memory compression (template)

> Rule: compression is NOT trusted until it passes. The exam is mandatory,
> every time, for every distilled block.

## Before compression
1. Write 10 control questions WITH answers, from the ORIGINAL text only.
   (Numbers, dates, decisions, doctrines. Writing them after compression = cheating.)

## Compression
2. Target corridor: 5–15% of the original size.
   - below 5% → almost surely lost something important
   - above 15% → it is not compression
3. List everything you deliberately dropped.
4. Move the original to an archive folder. Nothing is ever deleted.

## The exam
5. A COLD session (no access to the original) reads only the compressed block
   and answers the 10 questions.
   - Pass: >= 9/10. Below → fix the digest from the journal, re-exam.
6. Record: date, original size, compressed size, %, score.
